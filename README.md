# 🚀 Soluções Beecrowd — AED1 (UNIFESP)

Repositório dedicado ao armazenamento das resoluções dos exercícios da plataforma **Beecrowd**, desenvolvidas por mim durante a disciplina de **Algoritmos e Estruturas de Dados 1 (AED1)**, ministrada pelo **Prof. Arlindo** na **UNIFESP** (Universidade Federal de São Paulo).

---

## 📌 Sobre o Repositório

Este repositório contém as **minhas soluções autorais** para os problemas propostos. O objetivo principal é aprimorar a resolução de problemas com **foco central em lógica de programação, projeto de algoritmos e estruturas de dados**, buscando sempre código limpo, eficiente e bem estruturado.

* **Foco:** Lógica, Algoritmos e Estruturas de Dados
* **Linguagens:** C e C++
* **Plataforma:** [Beecrowd](https://www.beecrowd.com.br/)
* **Fluxo de Trabalho:** Envios diretos na branch `main`
