# 🚀 Beecrowd Solutions — AED1 (UNIFESP)

Repositório dedicado ao armazenamento das resoluções dos exercícios da plataforma **Beecrowd**, desenvolvidas durante a disciplina de **Algoritmos e Estruturas de Dados 1 (AED1)**, ministrada pelo **Prof. Arlindo** na **UNIFESP** (Universidade Federal de São Paulo).

---

## 📌 Sobre o Repositório

O repositório reúne soluções focadas em eficiência, legibilidade e boas práticas, abordando conceitos fundamentais da disciplina como estruturas condicionais, laços de repetição, vetores, matrizes, ponteiros e alocação dinâmica.

* **Linguagens:** C (predominante) e C++
* **Plataforma:** [Beecrowd](https://www.beecrowd.com.br/)
* **Fluxo de Trabalho:** Envios diretos na branch `main`
